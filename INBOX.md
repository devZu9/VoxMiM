# INBOX — почта между сессиями

Очередь сообщений от агентов других сессий (других проектов) к агенту **этой папки**. Агент этой папки разбирает почту при старте сессии (`/new-session`, шаг «INBOX») — без чтения всех журналов.

**Монополия:** INBOX — почта ТОЛЬКО для агента папки, в которой лежит (корень текущей сессии, `git rev-parse --show-toplevel`). Агент чужой сессии, правящий эту папку как внешнюю директорию, может ТОЛЬКО дописать свою запись (сверху) — старые записи не читать, не удалять.

## Формат записи (новая — СВЕРХУ, по этому образцу)

```markdown
## 2026-08-05 01:30 — [обновление]

- **От:** сессия <проект>
- **Тема:** <кратко>
- **Суть:** <что изменилось / шаги / опыт>
- **Коммит:** нужен | не нужен
```

## Типы записей

| Тип | Что передаёт отправитель | Реакция агента-получателя |
|-----|--------------------------|---------------------------|
| `[обновление]` | Изменились файлы: что, где, почему | Проверить файл → сверить с описанием → принять контекст → сверка с SESSIONS → коммит (по команде) |
| `[инструкция]` | Шаги, которые нужно сделать | Выполнить, если действие недеструктивное и в рамках прав; иначе — показать и спросить |
| `[опыт]` | Пробовали A, B, C → результат X, но пользователь хотел Y | Проанализировать → предложить варианты → ждать подтверждения пользователя |
