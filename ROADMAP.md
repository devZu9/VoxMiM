# Roadmap

> План разработки VoxMiM — порта VoxBee на Rust с исправлением ключевых ошибок.
> Правила оформления — скилл `logs-md-files` (глобальный). Насущные задачи — без привязки к версии; выполненное — в секциях версий (или в `logs_archive/roadmap/` для закрытых); идеи и отложенное — в `ROADMAP-IDEAS.md`.

## Тип модуля

**[SENSE]** — слух. Распознавание речи, голосовой ввод, wake word. Часть экосистемы DJA.

## v0.13.0 — Устойчивость whisper-сервера, валидация моделей *(текущая)*

- [x] **Устойчивость whisper-сервера** — новый модуль `src/stt/server.rs`: завершение только своего сервера (по PID и владельцу порта 8178), ожидание освобождения порта перед стартом, `/health` проверяется у живого нового процесса, защита параллельного старта (`startup_lock`); `taskkill /im` убран — чужие whisper-server (другие приложения/порты) не трогаются (21.08.2026)
- [x] **Валидация модели** — проверка магика `GGUF`/`lmgg` при загрузке и перед запуском сервера; несовместимые модели (PyTorch/zip и пр.) не запускаются с понятной ошибкой вместо падения сервера (21.08.2026)
- [x] **Смена модели в настройках реально применяется** — `load_model` вызывается при reload перед перезапуском сервера (раньше сервер перезапускался со старой моделью) (21.08.2026)
- [x] **Модальное окно «Модель не подходит» + откат** — при выборе несовместимой модели: окно с сообщением, по ОК — прежняя модель возвращается в config.json, сервер продолжает работать на ней; окно настроек подхватывает откат по mtime (21.08.2026)
- [x] **WM_TASKBARCREATED** — иконка трея пересоздаётся после перезапуска проводника (explorer); с ретраями NIM_ADD через таймер (300мс) с проверкой принятия — explorer не всегда готов в момент рассылки сообщения (21.08.2026)
